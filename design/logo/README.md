# Palang logo

The app icon (`data/icons/io.github.sahidev1.Palang.svg`) is sahi's leopard
design (`sahi-logo.jpeg`), traced into one SVG path with `trace.py` and put
amber on a dark tile. Nothing in this folder is built or installed; it's
kept so the icon can be redone or changed later.

- `sahi-logo.jpeg`: sahi's original drawing.
- `trace.py`: turns the drawing into the path (usage at its top).
- `drafts/`: the variants tried on the way (2026-10-22):
  - `a-round.svg`, `b-faceted.svg`, `c-black-jaguar.svg`: first drafts,
    drawn by hand. "A bit goofy."
  - `d-snarl.svg`, `e-panther.svg`: fiercer drafts. Not liked either.
  - `traced-*.svg`: the traced logo on other tiles. sahi chose amber on
    dark (the one in `data/icons/`).
- `sheets/`: the comparison pictures shown while choosing (each icon at
  256 px, and at 48 px below).
